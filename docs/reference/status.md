title: "Availability"

Fased includes Format-4 Local and mandatory-Tailscale Remote setup across Ubuntu 24.04+ (certified on `x86_64`), Debian 12/13, and Fedora 41–45 (`x86_64` & `arm64` with published dual-arch `v0.2.0` attested releases), cross-platform CLI & unsigned desktop pre-release packages (Linux, macOS, Windows), live AI providers with native OS-protected credentials, TypeSafe Jev & external MCP client, Agent V2 with `/api/v1/mcp`, operational diagnostics/backups, watch-only Solana wallets with live read-only RPC, and connected Stages 1–3 research, charting, intelligence, automation, QuantLab, and Paper/Shadow Desk workspaces. Mainnet real-money execution, default wallet signing, and in-app auto-updating remain strictly disabled by default (`walletSigner: false`, `financialExecution: false`, `hyperliquidActivationEnabled: false`), with an opt-in owner-gated Stage 4 non-WEN `--execution-profile=testnet` rehearsal profile; **WEN `SAT` mining execution is marked `NOT READY / DO NOT IMPLEMENT NOW`**.

Do not send funds to development addresses or enter wallet seed phrases or recovery keys. Use only the platform instructions and availability stated for your release.
