---
title: "Availability"
description: "What you can use and what is planned."
---

Fased includes certified Local and mandatory-Tailscale Remote setup on Ubuntu 24.04 x86-64, cross-platform CLI & unsigned desktop pre-release packages (Linux, macOS, Windows), live AI providers with native OS-protected credentials, TypeSafe Jev & external MCP client, Agent V2 with `/api/v1/mcp`, operational diagnostics/backups, watch-only Solana wallets with live read-only RPC, and connected Stages 1–3 research, charting, intelligence, automation, QuantLab, and Paper/Shadow Desk workspaces. Live wallet signing, real-money trading execution, and in-app auto-updating remain strictly disabled; **WEN `SAT` mining execution is marked `NOT READY / DO NOT IMPLEMENT NOW`**.

| Area                                 | Availability                                                                                                                                                                                                                                                |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ubuntu 24.04 Local/Remote install    | Certified & available for Ubuntu 24.04 x86-64 (attested `install.sh`, Local loopback and mandatory-Tailscale Remote with dual-stack nftables lockdown and shared UI/CLI updater).                                                                           |
| Cross-platform CLI & Desktop         | Available as unsigned pre-release packages (`install-cli.sh` for Linux/macOS, `install.ps1` for Windows, and native `.dmg`, `.exe`, `.deb`, `.AppImage` builds with `--upgrade`/`-Upgrade`); Apple/Windows signing pending.                                 |
| Trade charts & Orderflow             | Available (`#trade`: synchronized `1×1`–`4×4` Lightweight Charts v5, 9 candle transforms incl. Renko/Heikin-Ashi/Range/Tick/Volume, Footprint/DOM/Tape/VP/CVD, FasedScript chart overlays, chart event pins, Paper/Shadow Desk dock over `/api/v1/stream`). |
| News & Global Intel                  | Available (`#intel`: clean-room WorldMap, background GDELT/USGS/RSS/Macro/SEC sync, Polymarket↔Kalshi odds & arbitrage scanner, and clickable chart pins).                                                                                                  |
| Lab & 8-Seat Paper/Shadow Desk       | Available (`#lab`: sandboxed FasedScript DSL, deterministic 4-Gate validation, and 8-Seat Paper/Shadow Trading Desk with Trade Journal, Decay Monitor, Lessons, and kill switch — strictly `shadow`/`paper` only).                                          |
| Agents, Chat, Event Tasks & Telegram | Available (Agent V2 persistent `agents.sqlite` threads, FTS5 memory & rules, cron schedules + event triggers for price/indicator/FasedScript/news/prediction, fail-closed Telegram alerts & inline approvals, and 39 Agent V2 / 36 MCP tools).              |
| Providers, Jev & External MCP Client | Available (`codex`, `claude`, `antigravity`, `gemini`, `grok`, OAuth, API-key & local servers with OS vaults; TypeSafe Jev System-1 scoring + deterministic fallback; SSRF-guarded Streamable HTTP external MCP client).                                    |
| Diagnostics and backups              | Available (`fased-app doctor`, hot SQLite `fased-app backup` / `restore` covering core + Stage 1–3 databases, and portable watch-only wallet, RPC and venue backup/restore).                                                                                |
| Wallets and RPC                      | Watch-only Solana accounts and live read-only Solana RPC (keyless public RPC or OS-protected Helius/Alchemy/custom RPC key) available; real signing keys, funds custody and transaction signing remain strictly disabled.                                   |
| Onchain and Hyperliquid              | Live real-money trading is strictly disabled (`walletSigner: false`, `financialExecution: false`, `hyperliquidActivationEnabled: false`).                                                                                                                   |
| WEN `SAT` Mining                     | **NOT READY / DO NOT IMPLEMENT NOW** (`miningActivationEnabled: false`, decoupled from Stage 4 crypto gates and hidden from navigation until WEN Lean V1 Mainnet launch and explicit owner authorization).                                                  |
| Fased Network                        | Planned (`v0.2.0`).                                                                                                                                                                                                                                         |
| Updates                              | Shared UI (**Settings → Updates**) and CLI (`fased update`) on managed Linux (Manual default, Automatic opt-in); read-only release checks and opt-in `--upgrade`/`-Upgrade` on standalone desktop/CLI builds.                                               |

Do not send funds to development addresses or enter wallet seed phrases or recovery keys. Use only the platform instructions and availability stated for your release.

Read [Install](/guide/install), [Wallets](/guide/wallets) and the [Network guide](/guide/network).
