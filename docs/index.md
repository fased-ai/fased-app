Fased is a self-hosted app for trading research, strategies and approved automation. One Go engine serves the browser, desktop client and CLI; a separate signer enforces wallet authority.

**Install → Local or Remote → sign in → Dashboard.** Connect an optional provider, create an agent, use Chat and approve Tasks. Results and scoped memory stay connected. A deterministic task needs no AI account.

<Note>The new app is under development. Supported engineering paths have controlled verification; public distribution and owner/live acceptance remain open. Mining, live AI/wallet/trading and automatic/public updates remain disabled. See [Status](/reference/status).</Note>
