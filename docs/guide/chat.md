---
title: "Chat"
description: "Conversation, sources and concise proposals."
---

Choose an agent and persistent thread, enter a message (or use voice input where supported) and press **Send**. **Stop** cancels an active supported request. Use `/compact` to summarize long context cleanly across model switches and `/side` for ephemeral side questions that do not alter thread history. The selected account/model belongs to the shared Providers catalogue; switching it preserves conversation identity and drafts.

Sources, saved headlines, mirrored scheduled task runs and pinned or recalled memory can supply reviewed context. External news, web search citations, network signals and model responses are untrusted inputs. They cannot change wallet permissions or a reviewed strategy by themselves.

A Task proposal opens a review. Confirming creates the Task; merely reading the proposal does not schedule work. Completed scheduled runs mirror directly into agent threads so you can inspect and continue discussing them in Chat. Use **Remember** to save scoped context or rules; financial results remain in their journal. Compatible MCP clients can also connect to the local or owner-authenticated Remote `/api/v1/mcp` endpoint listed in Settings.

See [Providers](/guide/providers), [Tasks](/guide/tasks) and [Memory](/guide/memory).
