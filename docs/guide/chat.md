---
title: "Chat"
description: "Conversation, sources and concise proposals."
---

Choose an agent and conversation, enter a message and use **Send**. **Stop** cancels an active supported request. The selected account/model belongs to the shared Providers catalogue; switching it preserves conversation identity and drafts.

Sources, saved headlines, reminder runs and selected memory can supply reviewed context. External news, network signals and model responses are untrusted inputs. They cannot change wallet permissions or a reviewed strategy by themselves.

A Task proposal opens a review. Confirming creates the Task; merely reading the proposal does not schedule work. Inspect a completed run from Tasks and discuss its recorded result in Chat. Use **Remember** for useful scoped context; financial results remain in their journal.

Live provider requests remain disabled during this development stage. See [Providers](/guide/providers), [Tasks](/guide/tasks) and [Memory](/guide/memory).
