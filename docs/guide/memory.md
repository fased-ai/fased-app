---
title: "Memory"
description: "Scoped recall with correction and forgetting."
---

Memory keeps useful context for an agent: preferences, evidence and deliberately saved conclusions. It is separate from provider credentials, wallet secrets and financial records.

Use **Remember** on an eligible message or retained result. Inspect the source, correct an entry or **Forget** it. Entries stay with their selected agent, and recall follows your corrections and expiry choices. Changing providers does not create a new agent identity or move private memory to another profile.

A saved claim remains a claim. Memory does not become a current price, verified fill or spending permission. Improved recall is not model retraining or proof of improved trading returns.

Network publication is opt-in. Personal conversations, memory and portfolio details are not shared merely because the agent follows a publisher.
